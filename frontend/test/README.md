# UI 개선안 미리보기

`preview.html`을 브라우저로 열면 됩니다. 빌드도, 서버도, 설치도 필요 없습니다.

```
open frontend/test/preview.html      # 지도
open frontend/test/dictionary.html   # 기술 사전
```

앱과 같이 **두 페이지로 나뉘어 있습니다**. 상단바 토글로 서로 오갑니다.

## 이게 뭔가

프론트엔드를 이렇게 바꾸면 어떻게 되는지 **보기만 하는 사본**입니다.
`frontend/` 의 실제 코드는 **한 줄도 바뀌지 않았습니다** — Vercel에 올라가는 화면은
예전 그대로입니다. 이 폴더는 앱 빌드에 포함되지 않습니다(Next.js는 `app/` 아래만
라우트로 잡습니다).

## 실제 앱과 무엇이 다른가

| | 지금 배포본 | 이 미리보기 |
|---|---|---|
| 배경 | 남색 다크 (`#060c1c`) | 따뜻한 종이색 라이트 (`#f5f4f1`) |
| 강조색 | 청록 `#5bc0be` | 모노크롬 잉크 `#1b1916` |
| 히어로 | 첫 화면 전체를 차지 | 없음 — 바로 지도로 시작 |
| 사분면 설명 | 지도 위에 2×2 카드로 덮임, 스크롤하면 걷힘 | 모서리 이름표를 누르면 그 구역만 팝오버 |
| 상단바 | 페이지마다 링크 구성이 다름 | `지도 / 기술 사전` 토글 하나, 표시만 좌우로 미끄러짐 |
| 점 이름표 | 상시 표시 (많아지면 겹침) | 고른 점 하나만 |
| 스크롤 | 지도 구간에서 고정되며 멈칫함 | 그냥 흐름 |
| 글로우·광택 | 히어로 글로우, 호버 헤일로, 유리질감, 그레인 | 전부 없음 |

## 눌러볼 것

- 상단바 **지도 ↔ 기술 사전** — 알약이 좌우로 미끄러집니다
- 지도의 **30개 / 60개 / 전체** — 점이 한꺼번에 나타납니다 (예전엔 하나씩)
- 점에 **커서 올리기** — 툴팁이 점에서 26px 떨어져 뜹니다
- 점 **누르기** — 고리 + 이름표가 붙고 오른쪽 패널이 채워집니다.
  누른 뒤 30↔60을 바꿔보면, 그 기술이 판에서 빠질 때 고리가 남지 않습니다
- 상세 패널의 **채용 공고 추이** — Python(919건)은 증감률이 뜨고, AWS CloudFormation(12건)은
  `판단 유보`가 뜹니다. 표본이 적은 기술은 월별 증감을 추세로 읽지 않습니다
- 사전에서 **표제어 누르기** — 생태계 지표 막대, 이 자리에 있는 이유, 6개월 추세선,
  학습 자료가 펼쳐집니다 (지표·추세·자료 모두 임의값입니다. 학습 링크는 검색 결과로
  걸어둬서 눌리기는 합니다)
- 추세선 위에 **커서 올리기** — 세로선이 가장 가까운 달에 붙고, 제목 줄 오른쪽에
  그 달의 두 값이 함께 뜹니다. `표로 보기`를 열면 같은 값을 표로도 읽습니다
- 모서리의 **희소가치 / 필수 / 저관심 / 선점 후보** — 그 구역 설명이 뜹니다
- 사전을 한 화면 넘게 내리면 **오른쪽 아래 ↑ 버튼** — 맨 위로 돌아갑니다
- `Esc` — 열린 설명, 그다음 선택을 차례로 닫습니다 (사전에서는 펼친 표제어를 모두 접습니다)

## 파일

```
preview.html        지도 페이지        (앱의 / 에 해당)
dictionary.html     기술 사전 페이지   (앱의 /dictionary 에 해당)

preview.css         앱의 app/base.css + app/globals.css 를 합친 사본 (바뀐 스타일)
preview-extra.css   미리보기에서만 필요한 것 (배너, 정적 HTML이라 빠진 껍데기)

preview-common.js   두 페이지가 함께 쓰는 것 (사분면 메타 등)
preview-map.js      지도 동작    — 앱의 GapMap.jsx / DetailPanel.jsx
preview-dict.js     사전 동작    — 앱의 DictionaryClient.jsx
                    (펼침 패널·추세선·학습 자료가 여기 있다)
preview-data.js     lib/mockData.json 에서 화면에 쓰는 필드만 추린 사본 (200개)

mapPoints.test.mjs  지도 좌표 계산 검사 (frontend/lib/mapPoints.js 를 읽기만 함)
palette.test.mjs    팔레트 명암비 검사 (preview.css 의 토큰을 읽음)
```

검사 실행:

```
node frontend/test/mapPoints.test.mjs
node frontend/test/palette.test.mjs
```

## 알려진 한계

- **모바일(`/m`) 화면은 없습니다.** 데스크톱만 옮겼습니다.
- 직군 필터, 공고 목록, 기술 해설처럼 API가 필요한 것은 빠졌습니다.
- 데이터는 목업입니다.

## 추세선에 대해

채용 공고 언급과 생태계 열기는 원 단위가 다릅니다(건수 vs 지표). 축을 왼쪽·오른쪽
둘로 나누면 두 선이 만나고 갈라지는 자리가 아무 뜻도 없는 그림이 되므로, **둘 다
백분위 0–100 한 축**에 얹었습니다. 실제 건수는 커서를 올렸을 때와 표에서 읽습니다.

선 색(`--series-hiring` 파랑, `--series-eco` 앰버)은 색각 이상 조건에서 ΔE 19 이상으로
갈라집니다. 값은 사분면 색과 같지만 뜻이 다르므로 토큰 이름을 따로 뒀습니다.

## 상세 패널 통계 4칸

| | |
|---|---|
| **채용 수요** 백분위 · 활성 공고 건수와 순위 | **생태계 종합** 0~100 |
| **전월 대비 채용 공고** 점유율 지수 증감 | **전월 대비 생태계 활동** 점유율 지수 증감 |

앱은 `채용 공고 언급`(건수)과 `채용 수요`(백분위)를 따로 뒀는데, 같은 측정의 두
표현이라 한 칸으로 합쳤습니다. 비운 자리에 `전월 대비 채용 공고`가 들어갑니다.
막대 두 개(생태계 활동·채용 수요)는 위 타일과 같은 값이라 뺐습니다.

**증감은 건수가 아니라 점유율입니다.** 그 달 전체 공고에서 차지하는 비중을 첫 달
100으로 잡은 지수이고, 채용시장 전체가 커지거나 줄어드는 효과를 걷어냅니다.
생태계 쪽이 `scripts/build_tech_extras.py`에서 이미 쓰는 정의와 같습니다.

**표본이 30건에 못 미치면 증감을 내주지 않습니다**(`판단 유보`). 200개 중 절반이
전 기간 12건 이하 — 월 2건이 3건이 되면 +50%로 찍히는데 그건 추세가 아니라 그 달에
회사 하나가 공고를 더 올린 것입니다. 문턱을 넘지 못하면 스파크라인도 회색으로 둡니다.

추세 값은 전부 임의값입니다. 실데이터는 `GET /api/v1/timeseries`의 월별
`postingCount`에서 나옵니다 — 지금 프론트 어디서도 부르지 않는 엔드포인트입니다.
