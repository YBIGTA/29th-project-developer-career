# UI 개선안 미리보기

`preview.html`을 브라우저로 열면 됩니다. 빌드도, 서버도, 설치도 필요 없습니다.

```
open frontend/test/preview.html      # 지도
open frontend/test/dictionary.html   # 기술 사전
```

앱과 같이 **두 페이지로 나뉘어 있습니다**. 상단바 토글로 서로 오갑니다.

## 이게 뭔가

프론트엔드를 이렇게 바꾸면 어떻게 되는지 **보기만 하는 사본**입니다.
`frontend/` 의 실제 코드는 **한 줄도 바뀌지 않았습니다** — Vercel에 올라가는 화면은
예전 그대로입니다. 이 폴더는 앱 빌드에 포함되지 않습니다(Next.js는 `app/` 아래만
라우트로 잡습니다).

## 실제 앱과 무엇이 다른가

| | 지금 배포본 | 이 미리보기 |
|---|---|---|
| 배경 | 남색 다크 (`#060c1c`) | 따뜻한 종이색 라이트 (`#f5f4f1`) |
| 강조색 | 청록 `#5bc0be` | 모노크롬 잉크 `#1b1916` |
| 히어로 | 첫 화면 전체를 차지 | 없음 — 바로 지도로 시작 |
| 사분면 설명 | 지도 위에 2×2 카드로 덮임, 스크롤하면 걷힘 | 모서리 이름표를 누르면 그 구역만 팝오버 |
| 상단바 | 페이지마다 링크 구성이 다름 | `지도 / 기술 사전` 토글 하나, 표시만 좌우로 미끄러짐 |
| 점 이름표 | 상시 표시 (많아지면 겹침) | 고른 점 하나만 |
| 스크롤 | 지도 구간에서 고정되며 멈칫함 | 그냥 흐름 |
| 글로우·광택 | 히어로 글로우, 호버 헤일로, 유리질감, 그레인 | 전부 없음 |

## 눌러볼 것

- 상단바 **지도 ↔ 기술 사전** — 알약이 좌우로 미끄러집니다
- 지도의 **30개 / 60개 / 전체** — 점이 한꺼번에 나타납니다 (예전엔 하나씩)
- 점에 **커서 올리기** — 툴팁이 점에서 26px 떨어져 뜹니다
- 점 **누르기** — 고리 + 이름표가 붙고 오른쪽 패널이 채워집니다.
  누른 뒤 30↔60을 바꿔보면, 그 기술이 판에서 빠질 때 고리가 남지 않습니다
- 모서리의 **희소가치 / 필수 / 저관심 / 선점 후보** — 그 구역 설명이 뜹니다
- `Esc` — 열린 설명, 그다음 선택을 차례로 닫습니다

## 파일

```
preview.html        지도 페이지        (앱의 / 에 해당)
dictionary.html     기술 사전 페이지   (앱의 /dictionary 에 해당)

preview.css         앱의 app/base.css + app/globals.css 를 합친 사본 (바뀐 스타일)
preview-extra.css   미리보기에서만 필요한 것 (배너, 정적 HTML이라 빠진 껍데기)

preview-common.js   두 페이지가 함께 쓰는 것 (사분면 메타 등)
preview-map.js      지도 동작    — 앱의 GapMap.jsx / DetailPanel.jsx
preview-dict.js     사전 동작    — 앱의 DictionaryClient.jsx
preview-data.js     lib/mockData.json 에서 화면에 쓰는 필드만 추린 사본 (200개)

mapPoints.test.mjs  지도 좌표 계산 검사 (frontend/lib/mapPoints.js 를 읽기만 함)
palette.test.mjs    팔레트 명암비 검사 (preview.css 의 토큰을 읽음)
```

검사 실행:

```
node frontend/test/mapPoints.test.mjs
node frontend/test/palette.test.mjs
```
