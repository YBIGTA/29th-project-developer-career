# UI 개선안 미리보기

`preview.html`을 브라우저로 열면 됩니다. 빌드도, 서버도, 설치도 필요 없습니다.

```
open frontend/test/preview.html      # 지도
open frontend/test/dictionary.html   # 기술 사전
```

앱과 같이 **두 페이지로 나뉘어 있습니다**. 상단바 토글로 서로 오갑니다.

## 이게 뭔가

프론트엔드 개선안을 **빌드 없이 열어보는 정적 사본**입니다. 이 폴더는 앱 빌드에
포함되지 않습니다(Next.js는 `app/` 아래만 라우트로 잡습니다).

> **2026-08-23: 이 개선안은 실제 앱(`frontend/`)에 반영되었습니다.**
> 데스크톱 화면은 이제 여기와 같습니다. 이 폴더는 다음 개선안을 굴려보는
> 작업장으로 계속 씁니다 — 앱을 건드리기 전에 여기서 먼저 바꿉니다.

반영되지 않은 것은 **모바일(`/m`)** 뿐입니다. 미리보기에 모바일 화면이 없어
`app/mobile.css` 상단에서 예전 남색 다크 토큰을 그대로 되박아 두었습니다.

## 미리보기와 앱이 아직 다른 곳

**CSS는 완전히 같습니다.** `:root` 토큰 전부, 규칙 353개 전부 값까지 일치합니다
(`app/globals.css` ↔ `preview.css`). 아래 넷만 구조적으로 다릅니다.

| | 앱 | 이 미리보기 |
|---|---|---|
| 데이터 | 실제 API(없으면 `lib/mockData.json`) | `preview-data.js` 정적 사본 |
| 사전 표제어 | 217개(생태계 미수집 17개를 `BriefEntry`로 함께 실음) | 지표가 있는 200개만 |
| `지도 미표시` 배지 | 지도에서 잘린 표제어에 붙음 | 없음(어느 60개가 찍혔는지 사전이 모름) |
| 상태 화면 | 로딩 스켈레톤 · 에러 카드 · 지도 빈 상태 · `직군 데이터 없음` | 없음 — 정적이라 그 상태가 오지 않는다 |

그 밖의 화면은 같습니다. 사전 펼침 패널의 지표 막대·근거 문장·연관 기술 칩은
2026-08-23부터 앱과 같은 실측값을 그립니다(예전에는 기술명을 씨앗으로 지어낸
임의값이었습니다).

## 눌러볼 것

- 상단바 **지도 ↔ 기술 사전** — 알약이 좌우로 미끄러집니다
- 지도의 **30개 / 60개 / 전체** — 점이 한꺼번에 나타납니다 (예전엔 하나씩)
- 점에 **커서 올리기** — 툴팁이 점에서 26px 떨어져 뜹니다
- 점 **누르기** — 고리 + 이름표가 붙고 오른쪽 패널이 채워집니다.
  누른 뒤 30↔60을 바꿔보면, 그 기술이 판에서 빠질 때 고리가 남지 않습니다
- 상세 패널의 **개요 / 학습 / 채용 공고** 탭 — 배포본과 같은 구성입니다. 학습 탭은
  추천 영상이 있는 87개 기술에만 생깁니다
- 상세 패널의 **생태계 활동 추이** — 최근 8개월 점유율 지수입니다. 기준선(100) 위면
  초록, 아래면 빨강
- 사전에서 **표제어 누르기** — 생태계 지표 막대, 이 자리에 있는 이유, 함께 요구되는 기술,
  `어떻게 배우나`가 펼쳐집니다. 연관 기술 칩을 누르면 그 기술로 검색이 걸립니다. 학습 카드는 **공식 문서 1개 + 유튜브 영상 3개**이고 넷 다 썸네일이 보입니다
  (영상은 유튜브 썸네일, 문서는 그 사이트 파비콘 — 파비콘을 못 받아오면 머리글자 타일이
  남습니다). 주소와 제목은 실제 값이라 눌리면 진짜로 열립니다
- 모서리의 **희소가치 / 필수 / 저관심 / 선점 후보** — 그 구역 설명이 뜹니다
- 사전을 한 화면 넘게 내리면 **오른쪽 아래 ↑ 버튼** — 맨 위로 돌아갑니다
- `Esc` — 열린 설명, 그다음 선택을 차례로 닫습니다 (사전에서는 펼친 표제어를 모두 접습니다)

## 알려진 한계

- **모바일(`/m`) 화면은 없습니다.** 데스크톱만 옮겼습니다 — 그래서 앱의 `/m` 은
  아직 남색 다크입니다.
- 공고 목록은 `lib/mockPostings.json` 의 예시 공고 27개 기술분입니다. 배포본도 API가
  응답하지 않으면 같은 파일로 떨어집니다.
- 지표·순위는 `lib/mockData.json` 기준 목업이고, 학습 자료(공식 문서·영상)와
  생태계 활동 추이는 실제 값입니다.

## 상세 패널

배포본(`components/DetailPanel.jsx`)과 **같은 것을 그립니다.** 문구·섹션 순서·탭 구성까지
맞췄고, 다른 것은 색(라이트 테마)뿐입니다.

| | |
|---|---|
| **채용 공고 언급** 건수 | **채용 수요** 백분위 순위 |
| **생태계 종합** 0~100 | **전월 대비 생태계 활동** 점유율 지수 증감 |

아래로 생태계 3분해 막대, 생태계 활동 추이, 이 자리에 있는 이유, 함께 요구되는 기술,
지금 배운다면이 이어집니다.

**증감은 건수가 아니라 점유율입니다.** 같은 달 전체 기술 합계에서 차지하는 비중을 첫 달
100으로 잡은 지수이고, 플랫폼 전체가 커지거나 줄어드는 효과를 걷어냅니다. 정의는
`scripts/build_tech_extras.py` 상단 주석에 있습니다.

예전 미리보기에는 여기에 `채용 공고 추이`(임의값)와 `판단 유보` 규칙이 있었습니다.
배포본에 없는 것이라 뺐습니다 — 실데이터는 `GET /api/v1/timeseries` 를 붙일 때 옵니다.
